# Bubloo Scientist

Website replica draft with a responsive static frontend, editor interface, and Supabase database schema.

## Run locally

```sh
python -m http.server 4173 --directory dist
```

Open http://localhost:4173. No npm installation is needed.

## Included

- Article search, category filters, and article reader
- About, team, and contact sections
- Editor login and article management
- Supabase schema with row-level security

## Status

This is an unfinished draft. The logo and full content migration are pending, and Supabase is not connected. JavaScript syntax checks passed; browser and database tests are pending. Add contact rate limiting and bot verification before public launch.
